## Коротко

Тестирую программное обеспечение и разбираюсь, как оно устроено изнутри: от клиент-серверной архитектуры до запросов, которые уходят по сети. Понимаю жизненный цикл разработки и методологии, знаю, где в процессе появляется тестирование. Сейчас учусь автоматизации.

## Чем могу быть полезен

* Проверять веб-приложения: интерфейс и работу клиентской части.
* Тестировать мобильные приложения и анализировать их сетевой трафик в Charles Proxy.
* Разбирать запросы и ответы API: методы, заголовки, коды состояния, тело.
* Работать с базами данных через SQL (PostgreSQL).
* Готовить тестовую документацию: чек-листы, тест-кейсы, баг-репорты.
